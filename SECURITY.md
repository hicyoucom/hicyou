# Security policy

Please do not disclose a suspected vulnerability in a public issue or discussion.

Use GitHub's private vulnerability reporting feature for this repository. Include the affected version, a minimal reproduction, impact, and any proposed mitigation. Do not include real credentials or personal data; use reserved examples such as `example.com`.

Maintainers will acknowledge a complete report as soon as practical, investigate it privately, and coordinate a fix and disclosure based on severity. Only the latest release line receives security updates unless a release notice says otherwise.
